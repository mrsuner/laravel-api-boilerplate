# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-30

### Added

- Initial stable release of the Laravel 13 headless API application boilerplate.
- Sanctum token and cookie authentication, password, OTP, social authentication, and email verification flows.
- Laratrust roles and permissions, internal admin APIs, audit logging, file uploads, API response envelopes, rate limiting, Scribe documentation, Docker support, and AI-assisted development configuration.
- Official GitHub Template, Git clone, and Composer `create-project` distribution paths.
